01 The physics core

One hourly balance per row. Three inputs from weather: dry-bulb, dew point, solar. Everything else follows.

Wet-bulb

es(T) = 6.112 · exp(17.67 T / (T + 243.5))

es(Twb) − γ(Tdb − Twb) = es(Tdp),  γ = 0.000662·P

Magnus-Tetens saturation pressure. Psychrometric equation solved by 40-step bisection between Tdp and Tdb.

Pad outlet

Tpad = Tdb − η · (Tdb − Twb),  η = 0.82

The pad can only approach wet-bulb. When Twb is 30 °C, no pad gets the supply air to 25 °C.

Three modes, tested in order

  1. 1 · Dry Ventilation

    If outdoor air at full flow holds setpoint:
    T_out + Q_sens / (ρ·cp·Vmax + UA) ≤ T_set

    Fans at 0.010 m³/m²·s. No water, no AC.

  2. 2 · Fan-and-Pad

    If T_wb ≤ 23.5 °C and indoor at full flow ≤ T_set + 1.5 K.

    Fans at 0.050 m³/m²·s. Water = ρ·V·Δw·3600 × 1.12 bleed.

  3. 3 · Mechanical AC

    Otherwise. House sealed, held at setpoint:
    Q_AC = τ·G + UA·(T_out − T_set) + 15 W/m²

    Electricity = Q_AC / 3.2 COP + 4 W/m².

Switch threshold: above T_WB_CRIT = 23.5 °C the pad is not allowed to run, whatever the dry-bulb. In the July profile that is crossed between 06:00 and 07:00 AST.

    02 No-NetCDF fallback and run hash

    The engine looks for agrico_alkhor_era5land_202507.nc (ERA5-Land, nearest cell to 25.74° N, 51.47° E). If the file is absent, it builds a synthetic July: 31 days × 9 hours, sinusoidal dry-bulb 30→42 °C and dew point 20→26 °C, solar to 950 W/m², with Gaussian noise from numpy.random.default_rng(42).

    Same seed, same arithmetic, same CSV bytes. The SHA-256 of agrico_hourly_results.csv is the run hash. A calibration self-test checks the synthetic month against the reference case: mean daily peak 42.07 °C dry-bulb, 29.80 °C wet-bulb → PASS (±0.5 °C).

    Starts two separate Python interpreters (Pyodide, WebAssembly) in two web workers. Each one runs the unmodified engine file and hashes its own CSV.
